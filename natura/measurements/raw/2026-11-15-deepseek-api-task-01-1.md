# колбаса без сои и ГМО — какие марки в Беларуси

## Answer (cleaned)

Гарантированной «марки без сои и ГМО» нет: у одного и того же мясокомбината часть колбас может быть с соевым белком, часть — без. В Беларуси реально выбирать не по бренду, а по конкретной этикетке.

**Что смотреть в составе:**
- Лучше брать варёные колбасы/сосиски **по ГОСТ 23670-2019**, а не по ТУ.
- Не должно быть: «соевый белок», «изолят соевого белка», «концентрат соевого белка», «соевая мука», «растительный белок», «текстурированный растительный белок», «соевый лецитин / E322».
- Желательна пометка **«без ГМО»**, но она сама по себе не гарантирует отсутствие сои — состав проверять всё равно нужно.
- Для «Докторской» классический состав: говядина, свинина, молоко/яйца, соль, сахар, специи, нитрит натрия — без сои.

**У каких белорусских производителей чаще можно найти подходящие позиции** — но только проверяя каждый батон:
- Минский мясокомбинат
- Брестский мясокомбинат
- Гродненский мясокомбинат
- Слонимский мясокомбинат
- Борисовский мясокомбинат
- Витебский мясокомбинат
- Ошмянский мясокомбинат
- Пинский мясокомбинат
- Слуцкий / Могилёвский мясокомбинаты

Смотрите их линейки «Докторская», «Минская», «Брестская», «Гродненская», «Слонимская», «Борисовская», «Витебская», «Ошмянская», «Пинская» — но **только если на этикетке нет соевых ингредиентов и указано «без ГМО»/ГОСТ**.

Короткий вывод: покупайте не «марку», а конкретный продукт с коротким составом и отметкой «без ГМО»; при сомнении фотографируйте этикетку и сверяйте состав.
