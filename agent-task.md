# Задача агенту: GEO-замер брендов «Белорусская традиция» и Natura (Инко-Фуд)

## Цель

Измерить, как нейросети рекомендуют два бренда компании ИНКО-ФУД (Брест, https://beltradition.by/) в категории колбас и мясных изделий, и подготовить план повышения узнаваемости с приоритетами.

Итог работы: отчёт с цифрами по каждому бренду и план из 5–10 правок.

## Шаги

### 3. Замер

- **Движки:** минимум три. Основной состав: Алиса (Яндекс), ChatGPT, Perplexity. Если доступен Google AI Mode, добавь четвёртым.
- **Повторы:** 3 на промпт на движок. Каждый повтор — в новом чате, без истории и персонализации, иначе повторы не независимы.
- **Объём:** 30 промптов × 3 движка × 3 повтора = 270 ответов на бренд, 540 всего.
- **Веб-поиск:** включён во всех движках. Если в каком-то ответе поиск не сработал, отметь `web_search=false` в строке, не выбрасывай её.
- **Язык и регион:** русский; регион сессии не менять внутри волны. Зафиксируй его в отчёте.
- **Волна:** одна дата на бренд. Если замер не уместился в день, дели по брендам, а не внутри бренда.
- **Сырьё:** каждый ответ сохраняй целиком вместе со списком источников в
  `<бренд>/measurements/raw/<дата>-<engine>-<prompt_id>-<repeat>.md`.

### 4. Разметка

Один ответ = одна строка в `<бренд>/measurements.csv`. Колонки:

```
date,engine,prompt_id,scenario_class,weight,repeat,web_search,brand_mentioned,brand_role,brand_pos,competitor,competitor_role,brand_cited,competitor_cited
```

Правила:

- `brand_role`: `none` / `listed` / `recommended` / `top` / `negative`. Упоминание не равно рекомендации.
- `brand_mentioned=false` несовместимо с ролью `listed`/`recommended`/`top` и с позицией.
- `brand_cited=true`, если среди источников ответа есть `beltradition.by` или официальные страницы бренда в соцсетях. Цитирование и упоминание считаются раздельно.
- В `competitor` пиши конкурента с самой сильной ролью в ответе.
- Упоминанием бренда считаются все алиасы из брифа, включая «Инко-Фуд».

Особые случаи этих брендов:

- **«Белорусская традиция».** Словосочетание в общем смысле («по белорусской традиции делают…») упоминанием марки не считается. Засчитывай только когда речь о торговой марке или производителе Инко-Фуд.
- **Natura.** Засчитывай только мясную марку Инко-Фуд. Косметика Natura &Co, сыр Arla Natura, Via Natura и прочие омонимы — не упоминание. Если модель ответила про чужой Natura, поставь `brand_mentioned=false` и запиши случай в отдельный список `<бренд>/homonyms.md` с цитатой: это ключевой диагноз для бренда.

### 5. Скоринг

```bash
python3 scripts/geo_score.py --measurements <бренд>/measurements.csv --prompts prompts-<бренд>.csv
```

Запускай отдельно для каждого бренда. Все предупреждения скрипта (дубли, противоречия, недобор покрытия, n < 30) разбери до отчёта.

### 6. Диагноз и план

По каждому провальному сценарию определи причину по четырём корзинам навыка, в этом порядке:

1. бренда нет в источниках, которые цитирует модель;
2. контент не отвечает на интент промпта;
3. факты несопоставимы или не парсятся;
4. бренд не связан с категорией.

Приоритет правки = вес сценария × частота выпадения. Для каждой правки укажи ожидаемый эффект и способ проверки на следующем замере.

Гипотезы из предварительной разведки веб-поиска (10 запросов, не замер) — подтверди или опровергни данными:

- обоих брендов нет в подборках и обзорах белорусских колбас, там называют Пинский, Брестский, Гродненский, Могилёвский мясокомбинаты;
- название «Белорусская традиция» сливается с описанием категории и не опознаётся как марка;
- Natura вытесняется омонимами;
- отзывов о продукции на отзовиках и маркетплейсах почти нет;
- награды (например, 3-е место сосисок «NATURA ТРАДИЦИОННЫЕ» в отраслевом конкурсе produkt.by) нигде не используются.

### 7. Динамика

В этой задаче не выполняется. В отчёте укажи дату повторного замера: через 2–4 недели после внедрения правок, тем же набором промптов и теми же движками.

## Результат

Отдельная папка на каждый бренд:

```
<бренд>/brand.json
<бренд>/prompts.csv
<бренд>/measurements.csv
<бренд>/measurements/raw/*
<бренд>/homonyms.md        (только Natura, если были случаи)
<бренд>/plan.md
<бренд>/report.md
```

Плюс общий `summary.md`: сравнение двух брендов на одной странице и общие для компании правки.

Структура `report.md`:

1. Вердикт одной строкой: доля ответов, где рекомендуют бренд, и где конкурента.
2. SoV и win_rate по движкам с n, доля негатива, доля цитирования конкурентов.
3. Топ-5 провальных сценариев с дословной цитатой ответа (не длиннее одного предложения).
4. Источники, на которые модели опираются вместо бренда.
5. План: 5–10 правок, приоритет, ожидаемый эффект.
6. Чего данные не показывают: n, состав движков, регион, недетерминизм, доля ответов без поиска, границы волны.

## Ограничения

- Только измерение и план. Сайт, карточки и соцсети не править, ничего не публиковать и не отправлять от имени компании.
- Не регистрировать аккаунты и не принимать соглашения без подтверждения пользователя.
- Не вводить пароли, не проходить CAPTCHA. Если движок требует вход или проверку, остановись и сообщи пользователю.
- Числа и заявления из рекламных материалов GEO-сервисов в отчёт как факты не включать.
- Срез с n < 30 подавать как гипотезу, не как вывод.
- Если движок недоступен, не заменяй его молча: сообщи пользователю и предложи замену.
