## 6. Чего данные не показывают

- **Объём: n=48 вместо 270.** Замер урезан: ChatGPT (блок RU-IP), Perplexity (требует
  регистрации), DeepSeek (требует входа), Google AI Mode (требует входа) — недоступны
  без VPN/логинов; Qwen остановлен гостевым лимитом после 12 ответов, Алиса — по решению
  заказчика после 16 (гостевая сессия начала молча отбрасывать запросы), Z.ai — 20 ответов
  (прервано CAPTCHA).
- **Покрытие промптов: только класс category (46 ответов) и cmp-01 (2 ответа).** Классы
  task, trust, brand, risk не измерены — выводы по ним невозможны.
- **cmp n=2** — «бренд известен при обращении по имени» — гипотеза, а не вывод (n<30).
- **Natura: 0 ответов.** Отдельный замер Natura не состоялся; гипотеза об омонимах
  не проверена; `natura/measurements.csv` пуст.
- **Недетерминизм:** по 3 повтора на замеренные промпты; повторяемость вывода высокая
  (0% упоминаний в 46 категорийных ответах), но точные проценты на n<30 — ориентиры.
- **Регион и персонализация:** регион сессии не фиксировался инструментально (дефолт, RU-IP);
  Qwen/Алиса/Z.ai — гостевые или личные сессии, часть под учётной записью заказчика,
  в истории которой есть более ранние чаты с теми же промптами — риск лёгкой
  персонализации не исключён.
- **Поиск:** во всех 48 строках web_search=true (Z.ai — агентский поиск «N Searches»,
  Алиса — режим «Эксперт» с источниками, Qwen — включённый режим Web search); срез
  «ответ из памяти» не собран.
- **Волна:** одна дата (2026-11-15) — динамика отсутствует по определению; повторный замер —
  через 2–4 недели после внедрения правок (см. summary.md).
- **Разметка** выполнена агентом по сырым файлам; цитирование доменов проверено механическим
  grep по measurements/raw/*; роли конкурентов классифицированы по тексту ответов.
