# geo-incofood — GEO-замер брендов «Белорусская традиция» и Natura

Рабочее хранилище одного проекта: как нейросети рекомендуют два бренда компании ИНКО-ФУД
(Брест, `beltradition.by`) в категории колбас и мясных изделий. Здесь лежит всё, что получено
в ходе замера: брифы, промпты, сырьё ответов, разметка, отчёты, планы правок и скрипты прогона.

Методика, принципы и переиспользуемые инструменты (скоринг, шаблоны, сам навык) — в отдельном
репозитории [`Osmosy/vector-brand-control-agent`](https://github.com/Osmosy/vector-brand-control-agent).
Этот репозиторий — данные задачи, тот — метод. Общее у них только промпты и ТЗ.

## Что измерено

| Параметр | Значение |
|---|---|
| Волна | 2026-11-15 (базовая линия, до правок сайта) |
| Бренды | «Белорусская традиция», Natura (Инко-Фуд) |
| Промпты | 30 на бренд, 6 классов сценариев, веса 1–3 |
| Движки | Алиса (веб-поиск), DeepSeek в веб-интерфейсе, DeepSeek через API |
| Ответов | 450: «Белорусская традиция» — 270 (3 линии), Natura — 180 (2 линии) |
| Пилот Claude | отдельная волна 15.11.2026: 8 промптов × 3 повтора = 24 ответа на бренд |
| Регион сессии | РФ, язык русский |
| Повторы | 3 на промпт на движок, покрытие полное |

Не измерены: ChatGPT (блокировка по IP), Perplexity (гостевой лимит), Z.ai и Qwen (исключены
заказчиком), Google AI Mode (не отдаёт AI-ответ по этим промптам).

## Пилот Claude (отдельная волна)

`pilot-claude-2026-11-15/` — замер, сделанный не в этом пайплайне: движок Claude с веб-поиском,
8 промптов из 30 × 3 повтора = 24 ответа на бренд, все веса по 3. В основную волну не входит и в
общие метрики не складывается: другой движок, другой набор промптов, другая дата исполнения.

Коротко по разметке пилота (пересчитано по `measurements.csv`):

| Метрика | Белорусская традиция | Natura |
|---|---|---|
| Упоминания | 8 из 24 (33,3%) | 6 из 24 (25,0%) |
| Рекомендации | 0 | 3, все в сравнениях |
| Цитирование сайта бренда | 0 | 0 |
| Негатив среди упоминаний | 1 из 8 | 0 |

На тех же восьми промптах «Белорусская традиция» у Алисы набирает win 20,8%, у DeepSeek 4–8%,
у Claude — 0%. Структура упоминаний Natura у Claude и у DeepSeek API совпала по всем восьми
промптам, хотя файлы снимались в разное время: бренд всплывает только там, где производитель
назван в вопросе. Подробности и расхождения отчёта с разметкой — в `pilot-claude-2026-11-15/README.md`.

## Волна ZCode (три движка, частичная)

`wave-zcode-2026-11-15/` — ещё один независимый замер, сделанный вне этого пайплайна: 48 ответов
по «Белорусской традиции» на Qwen (12), Алисе (16) и Z.ai (20) и ноль по Natura. Покрыто 7
промптов из 30, 46 ответов из 48 — класс `category`. В общую волну не складывается.

| Метрика (48 ответов) | Значение |
|---|---|
| Упоминания бренда | 2 из 48, оба Z.ai на `cmp-01` |
| Категорийные ответы | 0 упоминаний из 46 |
| Цитирование `beltradition.by` | 1 из 48 |

Отдельно стоит сопоставление по Алисе: на тех же промптах `cat-01`–`cat-06` в этой волне 0
упоминаний из 16, в основной — 6 из 18. Один движок, одна машина, разница в типе сессии
(анонимная против аккаунта). Вывод: в брифе надо фиксировать не только движок, но и сессию с
режимом. Подробности и расхождения отчёта с сырьём — `wave-zcode-2026-11-15/README.md`.

## Как воспроизвести

Нужны: `python3`, `agent-browser` (для браузерных линий), ключ DeepSeek в `~/.hermes/.env`
(`DEEPSEEK_API_KEY`) для API-линии. Ключ в репозиторий не кладётся.

```bash
# браузерная линия (нужен живой браузер с залогиненной сессией движка)
python3 tools/geo_run.py --brand beltradition --engine alice --repeats 3
python3 tools/geo_refresh.py --brand beltradition --engine alice

# API-линия: сессия не нужна, каждый запрос чистый
python3 tools/geo_run_api.py --brand beltradition
python3 tools/geo_run_api.py --brand natura

# разметка и скоринг
python3 tools/geo_mark.py --brand beltradition
python3 ~/projects/vector-brand-control-agent/skills/vector-brand-control-agent/scripts/geo_score.py \
  --measurements beltradition/measurements.csv --prompts beltradition/prompts.csv

# цитаты для отчёта
python3 tools/geo_quotes.py --brand beltradition --prompts cat-02,cmp-01 --limit 1
```

## Формат разметки

`measurements.csv`, одна строка = один ответ:

```
date,engine,prompt_id,scenario_class,weight,repeat,web_search,brand_mentioned,brand_role,
brand_pos,competitor,competitor_role,brand_cited,competitor_cited
```

`brand_role`: `none` / `listed` / `recommended` / `top` / `negative`. Роль определяется по
предложению, заголовку блока («Топ», «Что брать», «Рейтинг») и по колонке «Место» в
markdown-таблице — без этого конкуренты из рейтингов остаются `listed` и SoV завышается.
`engine` различает каналы: `alice`, `deepseek` (веб), `deepseek-api` (память модели).

## Границы данных

- **Одна волна.** Сравнение с будущим замером — только тем же набором промптов и движками.
- **Каналы не равны движкам.** Алиса — поиск; DeepSeek в браузере и DeepSeek через API — одна
  модель в двух обвязках без веб-поиска (`web_search=false`, `citation_share=0` по определению).
- **Регион РФ.** Для Natura это может завышать провал в категории: категорийные запросы закрыты
  российскими марками. Повтор из BY-региона — отдельная задача.
- **Разметка автоматическая** по правилам задачи; спорные случаи (омонимы, общее употребление)
  вынесены в `homonyms.md` с дословными цитатами.
- **n по классам 24–54**, часть срезов на границе порога n≥30.
