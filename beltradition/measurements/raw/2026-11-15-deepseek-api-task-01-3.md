# колбаса без сои и ГМО — какие марки в Беларуси

## Answer (cleaned)

Однозначного списка «марок без сои и ГМО» по Беларуси нет: **бренд не гарантирует** — у одного и того же мясокомбината часть колбас идёт с соевым белком, часть без. Надпись «без ГМО» в Беларуси чаще добровольная, поэтому смотреть надо **на конкретный батон и состав**.

Реально искать среди продукции белорусских мясокомбинатов, особенно в позициях **по ГОСТ**:

- Минский мясокомбинат
- Брестский мясокомбинат
- Гомельский мясокомбинат
- Гродненский мясокомбинат
- Витебский мясокомбинат
- Могилёвский мясокомбинат
- Слонимский мясокомбинат
- Пинский мясокомбинат
- Кобринский мясокомбинат
- Волковысский мясокомбинат
- Борисовский мясокомбинат
- Слуцкий мясокомбинат
- Молодечненский мясокомбинат
- Ошмянский, Лидский, Берёзовский и др.

Чаще без сои бывают:

- варёная **«Докторская» по ГОСТ 23670-79**;
- варёная **«Любительская» по ГОСТ**;
- полукопчёная **«Краковская» по ГОСТ**;
- продукты из цельного куска — буженина, карбонад, ветчина из цельного мяса, но всё равно проверять рассол/состав.

В составе **не должно быть**: соя, соевый белок, изолят соевого белка, текстурированный соевый белок, соевая мука, «растительный белок» без расшифровки, «белковый стабилизатор» без указания происхождения.

Практический совет: берите колбасу с коротким составом и маркировкой **«ГОСТ»**, ищите на упаковке **«без ГМО»**, но обязательно читайте именно состав. Если нужна 100% уверенность — запрашивайте у производителя протокол/подтверждение на конкретную партию. Для магазина самый надёжный ориентир — не марка, а **конкретное наименование + состав + ГОСТ**.
